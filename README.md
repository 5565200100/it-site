# it-site

Персональный статический сайт (GitHub Pages, домен `itbad.de`). Без сборщика: чистый HTML/CSS/JS.

## Google Analytics 4

Сайт умеет показывать в Google Analytics, **какие страницы посещают** и **откуда приходят** люди (поиск, соцсети, прямые заходы, ссылки).

Чтобы включить:

1. Создайте ресурс в [Google Analytics](https://analytics.google.com/) (тип — Веб).
2. Скопируйте **Measurement ID** вида `G-XXXXXXXXXX` (Администратор → Потоки данных → выберите поток).
3. Вставьте его в `js/config.js` в поле `gaId`:

   ```js
   window.SITE = {
     /* ... */
     gaId: "G-XXXXXXXXXX"
   };
   ```

4. Закоммитьте и запушьте — GitHub Pages опубликует изменения.

Загрузка аналитики описана в `js/analytics.js` и подключена на всех страницах.
Если `gaId` оставить пустым (`""`), аналитика не подключается, и сайт работает как обычно.

> Сайт использует домен `.de`, поэтому действует GDPR. Текст политики конфиденциальности
> (`privacy.html`, словарь `js/i18n.js`) уже упоминает Google Analytics 4 и обезличивание IP.
