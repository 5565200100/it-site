# Персональный IT-сайт (GitHub Pages)

Статический сайт: HTML + CSS + JavaScript, без Node.js и сборщиков. Единственный внешний сервис — шрифт Exo 2 на главной (`index.html`, Google Fonts); без интернета используется системный шрифт. Языки: RU / EN / DE.

## 1. Локальный запуск
Откройте `index.html` двойным кликом. Для проверки в условиях, близких к GitHub Pages, можно запустить `python3 -m http.server` в папке проекта и открыть http://localhost:8000/.

## 2. Портрет
Положите фото в `assets/images/profile.png` (PNG с прозрачным фоном — силуэт отображается целиком, без обрезки) и укажите путь в `js/config.js` → `portrait`. Пока путь пуст, показывается силуэт.

## 3. CV
Положите файл в `assets/documents/cv.pdf` и укажите путь в `js/config.js` → `cv`. Пока путь пуст, кнопка CV не показывается.

## 4. Новое приложение
В `js/downloads.js` добавьте объект в массив `APPS` (скопируйте существующий). `name`, `short` (метка платформы), `tag` и `desc` — строка или `{ru,en,de}`. Поле `kind` (`ios`/`android`/`windows`) определяет кнопку платформы: App Store / Google Play / Windows. Поле `shots` — два скриншота `[{src, alt}]` (alt — `{ru,en,de}`), они показываются галереей над кнопкой. Скриншоты-заглушки — `assets/images/shot-*.svg`, замените реальными PNG и обновите `src`. Общее описание программы PDFSort — ключ `dl.about` в `js/i18n.js` (массив абзацев на ru/en/de). Уберите `placeholder:true`, когда данные реальные.

## 5. Ссылки на релизы
В записи приложения: `releasesUrl` (страница GitHub Releases), `storeUrl` (App Store), `downloadUrls.windows` / `downloadUrls.android`. Кнопка появляется только при URL, начинающемся с `https://`. Проверьте каждый URL вручную.

## 6. Биография и услуги
Все тексты — в `js/i18n.js`, отдельно для `ru`, `en`, `de`. Услуги — ключи `s1`…`s7` (`.t` название, `.d` описание, `.k` список задач, `.x` технологии; пустая строка скрывает строку технологий). Биография, опыт, проекты, навыки, сертификаты — `js/bio.js` (данные из CV, отдельно для ru/en/de). Блоки позиционирования: `bi.think` (3 карточки), `bi.process` (5 шагов), `bi.tech` (5 связей технология→ценность), `bi.market`. Проекты `bi.proj` содержат поля `problem`, `audience`, `decisions`, `quality`, `result`; пустое поле отображается как «к заполнению» (`bi.tba`). Имя, e-mail, LinkedIn — `js/config.js`.

## 7. Включение GitHub Pages
Репозиторий → Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)` → Save. Адрес: `https://USERNAME.github.io/REPOSITORY/`.

## 8. Проверка перед публикацией
- Заполнены `js/config.js`, `js/downloads.js`, тексты `bi.*` на всех трёх языках; нет `[...]` и «placeholder» в нужных местах.
- Просмотрите все страницы на RU, EN, DE (`?lang=ru|en|de`) на телефоне и компьютере.
- Пройдите сайт клавиатурой (Tab, Enter) и откройте консоль браузера (F12) — ошибок быть не должно.
- Откройте `404.html` через несуществующий адрес после публикации.

## 9. Собственный домен
Settings → Pages → Custom domain; создайте DNS-записи по инструкции GitHub. Если репозиторий называется `USERNAME.github.io` (сайт в корне) или подключён домен, в `404.html` переменная `ROOT_SITE` должна быть `true` для сайта в корне.

## Язык: как это работает
Приоритет: параметр `?lang=` → сохранённый выбор → язык браузера (`navigator.languages`) → английский. Параметр `?lang=` также запоминается как явный выбор. Кнопка языка одна: каждое нажатие меняет язык по кругу RU → EN → DE. Все внутренние ссылки получают `?lang=` текущего языка. Без `localStorage` сайт работает: язык берётся из URL или браузера.
На главной нет видимых элементов языка: нажмите **L** (смена языка по кругу) либо Tab — появится скрытая кнопка смены языка; также работает `index.html?lang=de`.

## Что нужно заменить
`js/config.js` (имя, фото, CV, LinkedIn, e-mail), `js/downloads.js` (приложения), `js/bio.js` (проверьте данные из CV), при желании `s*` в `js/i18n.js`, favicon (добавьте `<link rel="icon">` в HTML), `assets/images/profile.png`, `assets/documents/cv.pdf`.
В списках технологий услуг указаны C#/.NET, Swift/SwiftUI, Python, Flask — проверьте, что они соответствуют вашему опыту.
